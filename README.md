# Энисота: Хоррор-аддон для Minecraft Bedrock

Хоррор-аддон для **Minecraft Bedrock 1.20.1+**, добавляющий жуткого монстра **Энисоту** и систему кармы. Высокое чёрное существо с длинными руками и ногами появляется в темноте, а ваша карма (0–100%) определяет, будет ли оно враждебным или мирным. Карма повышается при кормлении животных, посадке семян и убийстве монстров; понижается при убийстве животных и жителей. При высокой карме Энисота иногда дарит предметы.

## Установка

1. Установите оба пакета: `BP` (поведенческий) и `RP` (ресурс-пак).
2. Для Windows 10/11 скопируйте папки в:
   - `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\development_behavior_packs` (BP)
   - `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\development_resource_packs` (RP)
3. Либо упакуйте каждую папку в `.mcpack` (zip с расширением `.mcpack`) и импортируйте двойным кликом.
4. В настройках мира включите оба пакета и **экспериментальные возможности** (Activate Cheats / Experimental).

## Использование

1. Зайдите в мир — при первом появлении получите **Артефакт кармы**.
2. Используйте артефакт (ПКМ), чтобы увидеть уровень кармы в чате.
3. Повышайте карму: кормите животных, сажайте семена, убивайте монстров.
4. При карме ниже 50% Энисота становится враждебной и атакует; выше 50% — мирная, при 70%+ может дарить подарки.
5. С каждым игровым днём Энисота появляется чаще.

## Файлы-заглушки

Перед запуском добавьте бинарные файлы:

- `RP/textures/entity/enisota.png` — текстура монстра (64×64)
- `RP/textures/items/karma_artifact.png` — текстура артефакта (16×16)
- `RP/sounds/enisota/creepy1.ogg`, `creepy2.ogg`, `whisper1.ogg`, `rustle1.ogg`, `rumble1.ogg` — звуки
